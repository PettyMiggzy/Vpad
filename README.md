# Meme World

Map, land and wars preview for launched coins. A coin claims land when its market cap reaches about $50,000 (about $9,200 of net USDC bought), holds it for 24 hours and has enough different buyers.

This is a static mock-up (open `index.html`); every number in it is invented. Real version: own server and land contract, after mainnet, wording to the lawyer first. Not public.


The game's contracts moved into the VYRE chain repo (`engine/contracts/game/`) so they deploy with the pad. This repo keeps the front end, the art and the flow.
